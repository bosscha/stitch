The Physics of N-Dimensions

Generalized Gauss's Law

In standard 3D space, gravitational flux spreads across the surface of a sphere (4πR²), resulting in the famous 1/R² inverse-square law.

In this project, we generalize Gauss's Law to N-dimensional space, where the surface area of a hypersphere scales proportionally to RN-1. Consequently, our N-Body GPU shaders dynamically scale gravitational force mathematically as:

F ∝ 1 / RN-1

Dimensional Behaviors

  • 1D Constant Force: 1/R° - Gravity does not decay with distance.
  • 2D Inverse Law: 1/R¹ - Force scales logarithmically with potential.
  • 3D Inverse-Square: 1/R² - Standard Newtonian gravity.
  • 4D+ Hyperspatial: 1/R³ and beyond - Extreme short-range decay.

Incoming Object Dynamics

Testing cluster stability against rogue hyper-massive objects.

We've implemented specialized simulation forks (rust_nbody_2D_incoming and rust_nbody_3D_incoming) to study the disruption of a perfectly virialized Salpeter-mass cluster.

  • Cluster Stars: 10,000 (King Model, Q=0.5)
  • Rogue Mass: 300 M⊙
  • Origin Point: 200 parsecs
  • Impact Velocity: 200 km/s

Technical Architecture

⚙️

Rust WGPU Engine

High-performance compute shaders executing on the Vulkan backend. Implements Velocity Verlet integration with batch command submission to prevent TDR timeouts during intense O(N²) gravity passes.

🔥

PyTorch ROCm

Vectorized Python implementations designed for AMD GPU tensor acceleration. Rapid prototyping for higher dimensions (up to 100D) using the astro_env Anaconda environment.

🐘

PostgreSQL Analytics

All snapshot geometries, phase spaces, and virial parameters are logged to a local PostgreSQL hypercluster database, easily queried via Julia and Python plotting suites.
